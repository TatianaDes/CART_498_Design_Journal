### Goal of the Prototype Week 3
The goal of my prototype is to have the user be able to navigate the performer's side of the application and see if it is easy to navigate and find all information. I am hoping to see if they can do all these steps:
1. Toggle to the performer's side of the application.
2. Find themselves on the map by street.
3. Drop a pin.
4. Set a timer.
5. Set the radius of the location.
6. Publish the performance.
7. See the timer.
8. See the tip jar.
9. Extend the performance.
10. End the set.
11. Use the application without WiFi.
12. Start over for a new performance.

My goal is to hopefully see where the weakest points are at the moment with my prototype, so that my next prototype cleans up and fixes the elements people were struggling with.
