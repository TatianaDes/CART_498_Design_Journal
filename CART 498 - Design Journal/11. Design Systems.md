### Main Components
I wanted to make sure the components for my application where mostly the components the user would be interacting with the most such as:
+ Buttons
+ Toggles
+ Drop downs
+ Any interface component that was repeated multiple times
+ Headings
+ Maps

### General Visual Guidelines of UI
Here are the principles of UI design I followed:
1. Hierarchy
+ I made sure that my headings and text had an evident difference with their size and boldness.
+ The buttons are large enough and most of the time in the center of the page for very clear visibility.

2. Progressive disclosure
+ Each page has the least amount of information and at least one or two interactions per page to keep everything clear and understandable.
+ There is an information button if users want to know more about the application capabilities.

3. Consistency
+ Kept the colours consistent so everything felt familiar.
+ The font is the same with only changes in size and boldness.
+ The buttons look similar with only the colours bein different.

4. Contrast
+ The colours are dark and blend into the background except for the buttons and navbar that have accent colours to separate itself from the rest.
+ Text on dark colours is white and text on light colours are black for visibility.

5. Accessibility
+ Dark mode and light mode.
+ Text is large to stay visible.
+ Important parts are highlighted with accent colours.

6. Proximity
+ Instructional text stays close to the button or drop down that can be interacted with for clarity.

7. Alignment
+ Aligned as much text and and buttons or other features as best as possible, so that each page consistently keeps the user not needing to look around the page for information.
