## Assumptions
1. There will need to be a toggle button for if the user is a performer or the audience
2. For performers, each action should take one to three clicks, and perhaps adding a search bar to find a location quickly on a map
3. For performers, the structure would be best if it was very linear that after each action a new very simple action follows, such as, find your location, drop a pin, a pop up comes up of what time the performance starts and when it ends, and then make it live.
4. For the audience, the map should be easy to navigate with performer's names popping up when the user scrolls closer to the locations.
5. For the audience, they need to easily be able to click on the names and get all the information they need on the who, what, where, and when.
6. For the audience, they will probably need a guide through the map from one location to another.
7. For the audience, they should be able to choose if they want notifications to be sent to them about specific performers and then also the set times.
8. If there is a messaging possibility between audience and performer, it has to be monitored to cause less harassment between performers and audiences.
9. There will have to be a button that anyone and everyone can press to go over each feature and how to use this application for a smoother experience.
