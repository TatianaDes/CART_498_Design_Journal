## Topic Selection:
### B2C Track - Corner Set
I would like to create a project using the Business to Customer market track because I have always really strived in listening to user feedback and doing my best to change elements of my work for the better. I think being able to create a system where I can create a website or an app that puts all its importance on creating user friendly experiences for all sides using it, will allow me to understand very different wants and needs and be able to find happy middle grounds. I also have always enjoyed creating visuals that are pleasant for users and that focus less on big and flashy adventures and more on what works with the website or app and what the users desire to see.
