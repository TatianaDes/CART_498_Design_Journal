## List of Features Week 2
1. Home page of a map with a search bar at the top for performers to find themselves
2. Create a pin once the user clicks on their location
3. Clicking on the pin will cause a pop-up window listing time and publish
4. Have presets to keep the experience as fast as possible in a dropdown
5. Have an extension button or toggle of how much longer the performance is going on for and have the audience able to manipulate it as well
6. Have pin automatically disappear when the event is over

## List of Features Week 3
1. Create an active set screen with a button for extending set time by 15 minutes each press.
2. Create an active Live Set screen with a countdown timer, current tip jar, and end set button.
3. The map should no longer be a specific location and instead just one street and a radius of how far it is from that street.
4. An icon indicating if the app is online or offline
5. A notification when WiFi goes down to indicate the change, but no change to the website itself.

## List of Features Week 4
1. The colours of the website should be bright and vibrant like the references.
2. The colours should change noticeably but subtly enough when switching between the performers and audience side.
3. Create a toggle with a sun and moon for light mode and dark mode.
4. Create a settings/more icon where users can find a blue light toggle on and off.
5. Reduce graphics to simple designs that can be distinguished immediately

## List of Features Week 5
1. In the more section of the audience side, there should be a notification on and off toggle for notifications when any artist that is a 5 minute walk away is starting to play.
2. The performer's side will have dots on the map that will represent open venue locations, they can click on and book.
3. The performer's search bar is where they can search up specific venue locations and/or neighbourhoods that have street spaces that performer's can have miniature shows at.
4. The audience's side will see pins on their map, the ones they click on will become bigger and have a different colour and show some information, while the other pins will be more faded and will only change once they are interacted with.
5. When a pin is clicked on and the audience can see information on the performer, there should be a little play button that can be clicked on and a 15 second clip from the performer's most popular song should play.
6. Next to the pins for the audience will be radiuses that say 200m for the closer pins and 500m for the pins that are further.
7. The audience's search bar is where they can look up specific artists or they can look up specific venues if they know exactly where they want to go. If not there is the map with pins they can interact with.
8. Keep palette small but festive.
