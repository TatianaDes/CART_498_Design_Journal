## Detailed Features Week 8-9
1. Make different sized rings (not necessarily circular) around the pins, that grow the more audience members there are at the venue. Stylistic sound waves design.
Having wavy rings around the pins with heat map colours for popular artists will be more eye-catching to the audience and make them want to see the artists that are the most popular, but also if they are not looking to be in a busy crowd they can also be aware of that. 

2. The pins that are of 100m or less, when clicked to see who the artist is an get a snippet, there will be another tab that will allow audience members to view the current setlist, and vote on the next track or encore by a pole.
Audience members will be able to not only see the artist and hear a snippet of their top song, but also depending on how close the audience member is to a pin, they will also be able to see the setlist (audience members will be in charge of setting that up to help one another), and vote through a pole on the next track or encore. The performer would be able to see the votes during the live set screen underneath the time and tip jar.
##### Performer's side:
3. Make the home page button on the navigation bar go to the beginning home page, not the audience or performer home page.
People are struggling with the fact that the home page button on the navigation bar does not go to the original home page and instead goes to the performer or audience home age, so to make it more understandable, the navigation bar for the home page will just go to the original home page. 

4. Make publish button bigger.
People are struggling to see the publish button, so it should be bigger and maybe have a more defining and vibrant colour.

5. Make yellows in the light mode darker, make blue-ish purples in the dark mode lighter.
The yellow in the light mode and the blue-ish purples in the dark mode are blending too much into the backgrounds. The yellow in the light mode should be darker, if not a different colour, and the blue-ish purples in the dark mode should be lighter or more blue.

6. Make the "You are now live!" bigger and bold.
"You are now live" text is not distinguishable enough, so it needs to be larger and bold.

7. WiFi not changing the website should be stated somewhere.
In the (i) section, there should be a brief explanation that this application works without WiFi.

8. Make title for extension button and the extension button itself more similar.
Either change the title to be more similar to the button or change the name of the button for the "extend set" button.

9. Make "extend set" and "end set" more different.
These buttons are too similar, so either they should be spread out more, very different sizes, or/and very different colours.

##### Audience's side:
10. Fix delay after paying.
The delay should either be quicker to go back to the pay page or instead of a delay there should be a button that brings the user back to the pay page.

11. Fix map in the directions page so the map in the background moves better.
Map seems to move and mess up the usability of the app in the directions page, that needs to be fixed.

12. Get a notification if the live performers 5 minutes away notification is turned on. (Coming soon)
A visual acknowledgement that the notification button has been turned on by a drop down alert of a performer being live 5 minutes away that when clicked brings the user to the directions page will be helpful.

13. Have a connection between the finding performers page and the tip page instead of just the navigation bar. (Coming soon)
Instead of only using the navigation bar to go to the tip jar page, there should be a way to get there either by the profile page when a performer is clicked on, or directly from the finding performers page.

Part B:
14. Make a very basic disappearing and reappearing navbar to, but because it is mouse position based, it must be worked on to be more mobile app friendly. 
Fixing everything did not give me time to properly do a "Part B" of my website, but I like the idea of having the navbar disappear or move based on how the user interacts with the app. It will be established better in future renditions.
